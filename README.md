# TranslateApi_Py

# Japanese
## 概要
本プログラムは「Translate API」です。
ライブラリとして「googletrans」および「FastAPI」を使用しています。
指定したテキストを任意の言語から別の言語へと翻訳し、結果をプレーンテキストで返却するAPIサーバーを提供します。

## 使用技術
- 言語: Python
- ライブラリ/フレームワーク: FastAPI, googletrans
- サーバー: Uvicorn

## 使い方

### 前提条件
- Python 3.x が動作する環境であること。

### インストール方法

1. リポジトリをクローンします。
```bash
git clone https://github.com/username/TranslateApi_Py.git
```

2. クローンしたディレクトリに移動します。
```bash
cd TranslateApi_Py
```

3. 必要なライブラリをインストールします。
```bash
pip install -r requirements.txt
```

### 基本的な使い方
以下のコマンドを実行し、APIサーバーを起動します。
```bash
python FastAPI.py
```

## 主な機能
- GETリクエストによるテキスト翻訳機能。
- パラメータとして、翻訳対象の文字列(`text`)、翻訳元の言語(`source`)、翻訳先の言語(`target`)を受け取ります。
- ローカル環境（`http://localhost` および `http://localhost:5000`）からのCORSリクエストを許可しています。

## 設定
CORSの許可オリジンなどの設定は、`FastAPI.py`ファイル内に記述されています。必要に応じてファイル内のリストを編集してください。

## APIリファレンス / ドキュメント
- エンドポイント: `GET /`
- クエリパラメータ:
  - `text` (str): 翻訳するテキスト
  - `source` (str): 翻訳元の言語コード (例: `en`, `ja` など)
  - `target` (str): 翻訳先の言語コード (例: `ja`, `en` など)
- 戻り値: 翻訳結果の文字列（プレーンテキスト）
- 補足: サーバーの起動後、ブラウザから `http://127.0.0.1:8000/docs` にアクセスすることで、FastAPIが自動生成するSwagger UIによるAPIドキュメントの確認およびテストが可能です。

# English
## Overview
This program is "Translate API".
The libraries used are "googletrans" and "FastAPI".
It provides an API server that translates a specified text from a source language to a target language and returns the result as plain text.

## Technology Stack
- Language: Python
- Libraries/Frameworks: FastAPI, googletrans
- Server: Uvicorn

## Usage

### Prerequisites
- Python 3.x environment

### Installation

1. Clone the repository.
```bash
git clone https://github.com/username/TranslateApi_Py.git
```

2. Navigate to the cloned directory.
```bash
cd TranslateApi_Py
```

3. Install the required packages.
```bash
pip install -r requirements.txt
```

### Basic Usage
Execute the following command to start the API server:
```bash
python FastAPI.py
```

## Key Features
- Text translation functionality via GET requests.
- Accepts parameters for the text to translate (`text`), the source language (`source`), and the target language (`target`).
- Allows CORS requests from local environments (`http://localhost` and `http://localhost:5000`).

## Configuration
Configurations such as allowed CORS origins are defined directly in the `FastAPI.py` file. Please edit the list in the file as needed.

## API Reference / Documentation
- Endpoint: `GET /`
- Query Parameters:
  - `text` (str): The text to translate.
  - `source` (str): The source language code (e.g., `en`, `ja`).
  - `target` (str): The target language code (e.g., `ja`, `en`).
- Response: The translated text as a plain string.
- Note: After starting the server, you can access `http://127.0.0.1:8000/docs` in your web browser to view and test the API using the Swagger UI automatically generated by FastAPI.
